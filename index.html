      How it works

      How the Cracker counts guesses

      The Cracker does not try every combination in order. It asks: what is the cheapest way to guess this? It splits your password into pieces and prices each one.

      • About you. Names, pets, teams and birthdays go to the front of the queue.
      • Common passwords. A list of the most-used ones, tried in order of popularity.
      • Words. A dictionary of about 57,000 English words, plus capital letters and swaps like @ for a.
      • Patterns. Years, dates, 123, qwerty and repeated chunks.
      • Brute force. Whatever is left is guessed blindly, character by character.

      The cheapest split wins. That number is the guesses the password survives.

      What “bits of entropy” means

      Entropy counts how many times the attacker’s work doubles. 10 bits is about a thousand guesses. 20 bits is about a million. 30 bits is a billion. Every extra bit doubles it.

      The Cracker’s bar shows effective entropy, the work a smart attacker needs. The marker shows theoretical entropy, which is just length times the size of the character set. Where the two disagree, the password is less random than it looks.

      Build your own checker (Python)

      A starting point for the Discovery Fortnight exercise. Run it, then improve it: add a bigger common list, catch years, or give a better label.

      import math
import re

COMMON = {"password", "123456", "qwerty", "iloveyou", "letmein"}

def strength(password, personal=()):
    """Return (bits, label). `personal` holds names, pets, birthdays."""
    pw = password.lower()
    if pw in COMMON:
        return 0, "Very weak: a common password"
    for word in personal:
        if word and word.lower() in pw:
            return 0, "Very weak: it contains your own details"

    pool = 0
    if re.search(r"[a-z]", password): pool += 26
    if re.search(r"[A-Z]", password): pool += 26
    if re.search(r"[0-9]", password): pool += 10
    if re.search(r"[^a-zA-Z0-9]", password): pool += 33
    if pool == 0:
        return 0, "Type something"

    bits = len(password) * math.log2(pool)
    for limit, label in [(28, "Very weak"), (36, "Weak"), (50, "Fair"),
                         (64, "Good"), (80, "Strong")]:
        if bits < limit:
            return round(bits), label
    return round(bits), "Excellent"

print(strength("Deva2005", personal=["Deva", "2005"]))
print(strength("purple-elephant-sings-quietly"))
      What this can and cannot tell you
      • The Cracker is a set of rules, not artificial intelligence. It can explain every number it gives.
      • Times are estimates. Real attackers use bigger lists, and hash speeds vary by machine.
      • Treat a good score as “hard to guess”, not “safe”. Reusing a password across sites defeats any strong password.
      • The best habit: a unique random password for every account, kept in a password manager, plus two-step login.
